# B6 金额仅退款与退货退款实施计划

> 执行方式：superpowers:subagent-driven-development；沿用用户已授权的当前工作区与分批实施方案。

Goal：实现已发货商品逐件金额仅退款、剩余实付退货退款、物流验收、独立入库恢复。
Spec：D:/cloud/TradeFlow-开发资料/docs/01-TradeFlow完整开发文档.md 第6节及03事务规范第6节、04接口规范。
Architecture：订单权威逐件权益与验收收据，售后持久编排，商品依据订单已验收收据回补，支付沿用双额度机制。MQ沿用B5。

## 约束与决定

- 不写/运行测试、业务请求或模拟消息；只做静态审查、跳过测试编译、迁移、启动、只读元数据。无SSH、commit、push。
- 所有新增业务方法中文注释，新表与字段中文COMMENT，已执行迁移不修改。RPC全部在数据库事务外。
- 金额整数分；同件一个有效售后；REFUND_ONLY 1分至剩余实付，库存不变；RETURN_REFUND退剩余全部，已全退金额不能再申请退款型退货。
- 仅已发货/已完成可申请新类型，完成后7天；未发货旧整单流程保留。商家同意原金额或拒绝。
- 退货审核后7天内填物流，超时与提交同主单锁竞争；已寄出不自动取消。验收全部通过或拒收，拒收留原因及证据、人工物流处置。
- 通过验收先保存不可撤销意图；订单记录RECEIVED并建立独立入库任务，即使退款失败也入库一次。退款和入库都完成才COMPLETED。
- Ruling：由订单持有验收收据与购买件绑定并编排库存，商品事务外查询订单确认收据；售后不自报SKU数量。沿用现有order→product身份和恢复边界。
- Ruling：用户已明确按既有文档继续开发，不重新发起方案审批；沿用当前checkout，无提交。

## 共享契约

RefundContracts已定义Allocation(orderItemId,unitNo,amountCents)、Reserve增加allocations（保留旧构造）；PreviewRequest/Preview/EntitlementUnit；ReturnAccept(orderNo,receiptNo)、ReturnReceipt(receiptNo,sourceNo,orderNo,reservationNo,status,lines)、ReturnLine(orderItemId,unitNo,skuId)、ReturnRestock。

- POST /internal/v1/aftersale-authorizations/preview -> Preview（aftersale）
- POST /internal/v1/refund-authorizations/{source}/return-receipt，ReturnAccept -> Authorization（aftersale）；固定RET:{source}，保存RECEIVED及入库任务，允许随后activate；未验收退货不得activate。
- GET /internal/v1/return-receipts/{receipt} -> ReturnReceipt（product/order）；status RECEIVED或APPLIED均为不可撤销实物事实。
- POST /internal/v1/inventory/return-restocks，ReturnRestock -> RestockView（order）；商品先查订单收据，事务中按预占→库存固定排序，保证每购买件只入库一次，累计不能超过原销售。
- 旧Authorization内容不变。支付允许售后来源三种类型，LATE_PAYMENT仍只order。

## 前置冲突检查

| 任务关系 | 产出与消费 | 结论 |
| --- | --- | --- |
| T1/T2 | ReturnReceipt→商品回补→RestockView | 固定契约，由root先写contracts，不交叉编辑 |
| T1/T3 | Reserve/Preview/ReturnAccept→Authorization | 冻结DTO及路径；终止墓碑需兼容新类型，不允许重用已终止来源 |
| T2/T3 | 商品配置/账号 | root负责脚本与共享配置，代理报告所需权限 |
| T1 | 不同件并发与终止/结算 | 禁止旧整单清零影响其他售后，逐件明细驱动行汇总 |
| T2 | 原销售上限与重复收据 | 不仅receipt幂等，唯一购买件防不同收据重复入库 |
| T3 | 验收后退款失败/超时 | 两条独立恢复路径，已验收不释放权益 |

## 审查重点

100元先退20再退80；同件并发与不同件独立；同来源异分配；验收成功退款失败仍入库；终止先到/旧任务围栏/重复成功不同eventId；输入主键字符串与期限边界；RPC无本地事务。
