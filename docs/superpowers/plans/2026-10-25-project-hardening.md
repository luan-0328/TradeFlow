# 单商家单仓库项目加固

用户批准执行审查建议，确认本轮保持单商家、单仓库。所有工作限本地，不连接或修改服务器，不引入Seata，不提交推送，不修改旧Flyway迁移或现有业务数据。

## 本轮业务约束

- 认可退货退款与可再售分离：每购买件明确SALEABLE、QUARANTINE、DAMAGED或SCRAPPED；仅SALEABLE增加可售库存。非可售库存有余额和不可变处置记录，后续处置也要权限、幂等、原子扣减和审计。
- 售后保存验收意图和逐件处置，订单核验其与原授权购买件完全匹配并形成不可变收据，商品仅依据订单权威收据处理。退款义务不取决于商品是否可再售。
- 历史已通过验收按旧业务语义回填SALEABLE；新增验收必须显式选处置，不缺省把质量问题商品恢复可售。重复同号不能改处置。
- 支付/退款回写必须校验owner、claim_version与有效租约，拒绝旧执行者并回滚本地效果；请求超时沿原业务号恢复。
- 入口保护跨实例共享计数，不使用JVM Map兜底；依赖异常明确拒绝受保护请求，错误码与Retry-After可读。来源默认socket地址，不盲信转发头。
- 备份校验/恢复验证必须在归属明确的全新隔离目标执行，真实数据库和Mock结果分别报告。
